# Completed Execution Plans

This folder is optional and short-lived. Keep only completion records that are still useful for immediate follow-up; delete generated plan artifacts once implementation is complete and no longer needed.

## What belongs here
- Completed plans with outcome notes.
- Canceled plans with rationale.

## Naming conventions
- Keep original file name from `active/` when moving.
- Add a short suffix when needed: `-completed` or `-canceled`.
- Include a completion date section inside the document.
