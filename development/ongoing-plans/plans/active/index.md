# Active Execution Plans

Keep in-flight execution plans for approved work.

## What belongs here
- Plans currently being executed.
- Plans waiting for review but still intended for current iteration.

## Naming conventions
- Use lowercase kebab-case: `feature-or-initiative.md`.
- Prefix with date for sequencing: `YYYY-MM-DD-feature-or-initiative.md`.
- Start each plan from `../execution-plan-template.md`.

## Lifecycle
- Generated plan drafts are temporary and should be deleted once implemented or superseded.
- Keep only plans that are actively guiding execution in this folder.
